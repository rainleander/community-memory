# Community Memory

> Making open-source knowledge discoverable.

Open-source projects generate valuable knowledge every day through:

- Issues
- Pull Requests
- Discussions
- Documentation

Over time, that knowledge becomes difficult to find, contributors repeatedly ask the same questions, and maintainers become the bottleneck.

Community Memory is an experiment in helping communities preserve, discover, and reuse project knowledge.

## The Problem

A contributor asks:

> Why was this architecture chosen?

The answer exists somewhere in the project's history, but finding it may require digging through years of issues, reviews, discussions, and documents.

The knowledge isn't lost.

It's fragmented.

## The Vision

Community Memory explores approaches for:

- Historical design decision lookup
- Architecture knowledge capture
- Contributor FAQs
- Governance history
- Search across project artifacts

The goal is simple:

> Help contributors find project knowledge without needing to know where it lives.

## Contribute

Community Memory is intentionally early stage and community-driven.

Whether you have a use case, template, experiment, or strong opinion, we'd love to hear from you.

See CONTRIBUTING.md.

## Why This Matters 

We've gotten very good at scaling code. 

Now it's time to scale knowledge.
